Wi-Fi 経由のアップデート ＆ Wi-Fi 2件登録に対応（最新・版3.1）

すでに動いているセンサー箱は、USBケーブル不要でスマホやPCから Wi-Fi 経由でそのまま版3.1へ更新でき、更新後に画面から2つ目の Wi-Fi（お店／自宅）を追加登録できます。
新しく別の Pico W に書き込む場合も、下のブラウザ直接書き込み（最大2つのWi-Fi同時登録可）または ZIP 一式ダウンロードが使えます。

📶 USB不要・Wi-Fi更新 いま動いているセンサー箱を Wi-Fi 経由で最新版（版3.1）にする

⬇️ Wi-Fi更新用ファイル「センサー箱_TSD10版3.1.mpy」をダウンロード（約45KB）
📱 スマホ（iPhone等）または PC からの更新手順（約30秒・フタを閉じたままOK）：
  1. 上の緑ボタンを押して センサー箱_TSD10版3.1.mpy を保存します。
  2. センサー箱の状態ページ（例：http://192.168.1.20/）を開き、一番下の 「プログラム更新」 をタップします（※版3.0から更新するときだけ、センサーの前1.5m以内に物がない向きにして送るとスムーズです）。
  3. 保存した センサー箱_TSD10版3.1.mpy を選んで 「送る」 → 「更新を適用」 を押すと、約25秒で自動的に 版3.1 に切り替わります（失敗しても自動で元の版に戻る安全設計です）。
  4. 更新後、状態ページに新しく増える 「Wi-Fi 設定（2つまで登録）」 を開くと、② 2つ目の Wi-Fi（お店／自宅） をそのまま追加保存できます！

初回USB書き込み Chrome / Edge から直接 Pico W に一発書き込み＆動作チェック（Wi-Fi 2件対応）

💡 新品の Pico W を箱から出したばかりのときだけ（3秒）：
USB を挿したときにパソコンに RPI-RP2 ドライブ が開いた場合は、先に下のボタンから MicroPython 本体（.uf2） をダウンロードして RPI-RP2 ドライブへドラッグ＆ドロップしてください（数秒でドライブが閉じて COM ポートになり、下のボタンから書き込めるようになります）。
⬇️ 新品 Pico W 用 MicroPython 本体 (.uf2) をダウンロード
🔒 入力した Wi-Fi 名とパスワードはこのブラウザ内だけで wifi_secret.py を作って目の前の USB ケーブルへ送るためだけに使われます（外部サーバーへの送信は一切ありません）。
⚠️ お使いのブラウザは Web Serial API に対応していません（Safari / Firefox / スマホ等）。パソコンの Google Chrome または Microsoft Edge で開くか、下の「ソフト一式まとめてダウンロード (.zip)」をお使いください。
